# Alfred UI checker

`check_ui.py` checks a workflow folder's Alfred UI bundle and `info.plist` against the Alfred UI schema. `make check-window` runs it on the assembled workflow, and so does CI.

It is a copy, unchanged, of `skills/alfred-ui/scripts/check_ui.py` from [Hemmingsson/alfred-ui-skill](https://github.com/Hemmingsson/alfred-ui-skill) at commit `568838517f2ab5597d047f01408bcd24ff52d734`, MIT licensed; see `LICENSE`. To update it, copy the newer file over this one and change the commit here.
